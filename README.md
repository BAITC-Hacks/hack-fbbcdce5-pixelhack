# EKT AI Assistant

ИИ-ассистент для консультации клиентов интернет-магазина **ekt.kz**, разрабатываемый в рамках **HackAlem AI**.

## 1. Описание

Клиенты ekt.kz сталкиваются с необходимостью обращаться к менеджеру для получения информации о товарах, технических характеристиках, сертификатах, наличии, аналогах и условиях покупки.

Цель проекта — создать ИИ-ассистента в едином окне чата на сайте ekt.kz.

Ассистент должен:

* консультировать по каталогу;
* предоставлять информацию о товарах;
* показывать технические характеристики;
* предоставлять информацию о сертификатах;
* проверять наличие товара;
* предлагать релевантные аналоги при отсутствии товара;
* отвечать на вопросы об условиях покупки;
* добавлять выбранные позиции в корзину только после явного подтверждения пользователя;
* учитывать запрашиваемое количество и доступный остаток;
* после добавления предоставлять ссылку на корзину/оформление заказа.

## Требования к ассистенту

### Работа с товарами

Ассистент должен уметь отвечать на вопросы о товаре на основе данных каталога:

* наименование;
* технические характеристики;
* сертификаты;
* цена;
* остаток;
* статус наличия.

### Аналоги

Если нужного товара нет в наличии, ассистент должен предложить минимум один релевантный аналог и кратко объяснить причину рекомендации.

### Условия покупки

Ассистент должен отвечать на вопросы об:

* оплате;
* доставке;
* минимальной партии.

### Корзина

Ассистент не должен изменять корзину без явного подтверждения пользователя.

После подтверждения количество добавляемого товара не должно превышать доступный остаток.

После успешного добавления пользователь должен получить прямую ссылку на актуальную корзину/оформление заказа.

---

## Ограничения

Система не должна:

* изменять состав корзины без явного подтверждения клиента;
* оформлять заказ без явного подтверждения клиента;
* сообщать недостоверные данные о цене;
* сообщать недостоверные данные о наличии;
* запрашивать или хранить платёжные данные клиента.

Также необходимо учитывать:

* приватность пользовательских данных;
* защиту корзины от несанкционированного изменения;
* объяснимость рекомендаций аналогов;
* совместимость с платформой сайта;
* поддержку desktop и mobile.
